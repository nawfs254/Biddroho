# Biddroho

Official digital platform, content management suite, and operational ledger for **BIDDROHO** (Heavy Rock Band).

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Vanilla CSS & Modern Design System
- **Database:** MongoDB
- **Authentication:** Custom JWT-based RBAC with Secure Cookies
- **Visuals:** Ambient Rock Audio Visualizers, Music Loaders, & Custom Interactive Audio Player

## Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
